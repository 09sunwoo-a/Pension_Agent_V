# Source Registry

이 문서는 Source Corpus 탐색을 위한 색인이다.

- Knowledge Base가 아니다.
- Case와 관련된 Source 후보를 좁히는 데 사용한다.
- Description과 Topics는 탐색용 Metadata이다.
- Authority / As-of / Status가 명확하지 않으면 추정하지 않는다.
- 실제 판단에 사용할 내용은 반드시 원 Source를 직접 확인한다.
- Case 결과나 사용 빈도를 Registry의 의미에 섞지 않는다.
