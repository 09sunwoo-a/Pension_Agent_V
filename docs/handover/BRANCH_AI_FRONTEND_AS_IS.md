# 부점 AI 현재 구현 요약

기준: 2026-09-20 프론트 골든 시연 구현. **로컬 규칙·템플릿으로 계산하며 실제 부점 Agent/LLM 미연결**. [기능·골든 기준](BRANCH_AI_SEARCH_DESIGN.md)과 해당 코드만 먼저 읽는다.

다음 단계의 요청·응답·화면 조작·멀티턴 설계는 [Agent 작업 안내](branch-agent/README.md). 현재 코드에 이미 적용되었다고 해석하지 않는다.

## 2. 상태·UI 원칙

- 메인48명(구조화31·표시 정보만17). 추천3명 기준일09.14, 전체 자료는09.04/09.14/미확인 혼재. 원본 JSON 변경 없음.
- 검색·추천은 목록 교체, 통계·간단 브리핑은 목록 유지. 집계 대상 보기만 명시적으로 적용. 목록과 집계군이 다른 직후 ‘그중’은 범위 확인.
- 조건 추가는 현재 결과 안에서, 제거는 조작 이력 재계산. Top N 밖 고객 보충 금지. 추천은 ID/3명 고정 없이 근거 평가·중복 제거.
- 새 대화는 메시지만 초기화하고 목록·조건·추천 보존. 기존 목록은 기본 목록 복원·조건/추천 해제. 취소/오류/늦은 응답은 이전 확정 상태 유지.
- **메인 화면 원형 유지:** 상단·KPI·고객 카드·상세 이동을 바꾸지 않는다. 검색은 기존 행 선택/순서·검색 결과 제목만 반영. 근거·브리핑 버튼·조건 조작·0명 복구는 대화창 안에서 처리한다.
- 메인 상단의 기존 시연 문구·수치는 원래대로 보존하며, AI가 계산한 통계와 자동 연동된 것으로 간주하지 않는다.
- 기본6초 대기(`branchSearchLatency`), 목록 변경 의도일 때만 스켈레톤·도넛·진행선. 결과 약900ms 등장, 새 고객만 회청색 테두리. 같은 결과/정렬만 변경은 제목 효과.
