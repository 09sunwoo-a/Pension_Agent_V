## 표 읽는 법

- **활용 위치** — S2: 이번 제안을 검토할 이유·고객 이점 / S3: 관리방향·운용 선택지 / S4: 설명·예상 질문·반론 대응 참고 / S5: 관련 Hot Tip·업무지식·실행지원. S1(고객 DATA)은 이번 매핑 대상이 아니며, 원천자료 속 고객 사실을 S1 근거로 가져오지 않았다.
- **짧은 근거 내용** — `[발췌]`는 원문 그대로, `[요약]`은 원문을 충실히 정리한 것. 혜택과 적용조건을 함께 남겼고, 원문의 `확인 필요`·`추론`·시점 한정 표시는 그대로 두었다. 고객 화법으로 재작성하지 않았다.
- **출처 표시명** — 실제로 읽은 원천을 우선 기록. 제목·날짜·번호는 자료에 있는 것만 사용했고, 날짜가 없으면 '기준일 미표기'로 남겼다. KBthink는 저장소의 md 정리본(`04_KBthink_연금/`)을 읽은 것이며 웹 원문은 열지 않았다. Hot Tip은 개별 직원의 현장 경험담이다.
- **원천 위치** — 실제 읽은 파일의 저장소 상대경로와 소제목·줄번호(`L`), 탐색에 쓴 추출지식 항목(`탐색:`). 자료에 기재된 원문 URL은 `자료 기재 URL`로 구분했고, 해당 웹페이지를 읽은 것은 아니다.
- **확인 상태** — `원천 본문 확인` / `정리본만 확인` / `근거 미발견`. 자료를 읽었는지의 상태이며, 현행 제도·업무조건의 검증 완료나 대고객 안내 승인을 뜻하지 않는다.
