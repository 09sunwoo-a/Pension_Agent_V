# 퇴직연금 Agent — 일반 운용전략 Master Knowledge Base

> 목적: 퇴직연금 사후관리 Agent가 고객별 브리핑(S1~S5)을 생성할 때 활용할 수 있도록,  
> 특정 Trigger 중심의 Golden Case와 별도로 **일반적인 퇴직연금 운용전략**을 정리한 Master Knowledge Base.
>
> 작성 원칙
> - 원천자료에 명시된 내용 중심으로 추출
> - 기존 전략과 실질적으로 동일한 경우 신규 Strategy를 만들지 않고 기존 카드에 보강
> - 연령/비중 등 자료 간 기준이 충돌하는 경험칙은 강제 Rule로 사용하지 않고 참고 원칙으로 일반화
> - Strategy / Product Knowledge / Execution Knowledge / Tactical Strategy를 분리
> - Agent는 상품부터 고르지 않고 `자금의 성격 → 투자기간 → 목표수익 → 허용 변동성 → 자산배분 → 운용방식 → 상품` 순서로 판단

---

# 1. Knowledge 구조

## 1.1 General Strategy

```text
고객의 생애주기·투자성향·자산상태·투자가능기간
→ 원래 어떻게 운용해야 하는가?
```

## 1.2 Golden Case

```text
특정 Trigger / 이벤트 발생
→ 왜 지금 관리해야 하는가?
→ 어떤 상담 / Action이 필요한가?
```

## 1.3 Product Knowledge

상품 자체의 구조와 특징.

예:
- 정기예금
- GIC
- ELB
- 펀드
- ETF
- TDF
- 디폴트옵션

## 1.4 Execution Knowledge

운용전략을 실제로 실행할 때 필요한 제도·절차·거래조건.

예:
- 만기상품 변경예약
- 디폴트옵션 적용절차
- 중도해지이율
- 상품별 매도·정산기간
- 위험자산 한도
- 상품 가입가능 여부

## 1.5 Tactical Strategy

시장환경에 따라 달라지는 전략.

예:
- 금리 상승기 / 하락기 채권 듀레이션 조절
- 원리금보장상품 만기구조 조정
- 시장 국면별 자산군 판단

# 2. Agent 상위 판단 Framework

## RS-18을 포함한 공통 Reasoning Backbone

```text
① 자금의 성격 규정
        ↓
② 실제 투자가능기간 계산
        ↓
③ 목표수익률 설정
        ↓
④ 허용 가능한 변동성 / 손실 수준 판단
        ↓
⑤ 적정 자산배분 결정
        ↓
⑥ 직접관리 vs 관리형 운용 판단
        ↓
⑦ 상품으로 구현
        ↓
⑧ 정기 점검 / 리밸런싱
```

Agent는 다음과 같은 방식으로 상품부터 바로 추천하지 않는다.

```text
ETF를 추천할까?
TDF를 추천할까?
정기예금을 추천할까?
```

가 아니라,

```text
이 돈은 언제 쓸 것인가?
얼마나 오래 운용할 수 있는가?
어느 정도 손실을 견딜 수 있는가?
어느 정도 수익이 필요한가?
직접 관리할 수 있는가?
        ↓
어떤 자산배분이 적절한가?
        ↓
그 자산배분을 어떤 상품으로 구현할 것인가?
```

순서로 판단한다.

# 4. Strategy Cards

## RS-01. 장기 운용기에는 적립식·분산투자로 성장자산 활용

### 적용 상황
- 30~40대 등 은퇴까지 충분한 기간이 남은 고객
- 향후에도 정기적인 추가 납입이 예상되는 고객
- 단기간 사용할 예정이 없는 노후자금
- 투자성향상 실적배당형 자산을 감내할 수 있는 고객

### 핵심 원칙
퇴직까지 시간이 충분한 고객은 단기 시장변동보다 장기적인 자산 증식 관점에서 운용하며, 투자성향이 허용하는 범위에서 실적배당형 자산을 활용한다.

### 운용 방향
- 목돈 일시투자보다 적립식·분할투자 검토
- 특정 상품·섹터 집중보다 자산·지역·시간 분산
- 원리금보장형에만 머물기보다 성장자산 일부 활용
- 단기 수익률보다 장기 투자원칙 유지

### 판단 변수
- 연령
- 예상 은퇴시점
- 실제 투자가능기간
- 투자성향
- 정기 납입 여부
- 단기 자금사용 계획
- 현재 자산배분
- 특정 자산·국가·섹터 집중도

### Agent 판단 로직
```text
투자가능기간 충분
+ 지속적 추가납입 가능
+ 실적배당 투자성향 허용
→ 장기 성장자산 활용 필요성 판단

원리금보장 비중 과다
→ 실적배당형 비중 확대 검토

특정 국가/섹터 집중
→ 자산·지역 분산 검토

목돈 일시투자 예정
→ 적립식·분할투자 검토
```

## RS-02. 특정 국가·섹터·상품 집중보다 실질적 자산·지역 분산

### 적용 상황
- 여러 상품을 보유하지만 실제 투자대상이 동일 국가·산업에 집중
- 특정 ETF·테마·국가에 높은 비중으로 투자

### 핵심 원칙
상품 개수가 많다고 분산된 것은 아니다. 실제 투자대상과 Exposure를 기준으로 국가·시장·자산군이 충분히 분산되어 있는지 판단한다.

### 운용 방향
- 상품 수가 아니라 실질 Exposure 기준으로 집중도 확인
- 주식·채권·금 등 상관관계가 다른 자산 활용 검토
- 특정 국가·섹터 집중 시 글로벌·다자산 분산 검토

### 판단 변수
- 상품별 투자국가
- 섹터/테마
- 자산군
- 실질 Exposure
- 특정 국가/테마 합산 비중

## RS-03. 장기 노후자금은 정기예금·현금성자산에만 머물지 않도록 운용

### 적용 상황
- 은퇴까지 시간이 충분한데 정기예금·현금성 중심으로 장기간 운용
- 단기 사용계획이 없는 장기 노후자금

### 핵심 원칙
장기 노후자금은 원금손실 가능성뿐 아니라 물가상승에 따른 실질가치 하락도 함께 고려한다. 단기 유동성 목적이 아니라면 투자성향 범위 내에서 장기적인 실질수익을 확보할 수 있는 자산 일부 활용을 검토한다.

### 운용 방향
- 단기 사용예정 자금은 안정성·유동성 우선
- 장기 자금은 물가상승과 복리효과 고려
- 투자성향에 따라 실적배당형 일부 편입 검토

### 판단 변수
- 자금 사용예정 시점
- 실제 투자가능기간
- 원리금보장/현금성 비중
- 투자성향
- 장기 실질수익률

## RS-04. 기대수익보다 실제 투자성향·손실감내도를 먼저 판단

### 적용 상황
- 높은 수익을 원하지만 손실은 감수하기 어려운 고객
- 주변 인기상품을 따라 투자하려는 고객
- 실제 투자성향과 기대수익이 불일치하는 고객

### 핵심 원칙
높은 수익을 원한다는 것과 공격투자형이라는 것은 다르다. 실제 손실감내 수준, 투자경험, 자금 성격, 투자기간을 기준으로 위험수준을 결정한다.

### 판단 변수
- 투자성향
- 연령
- 투자경험
- 재산·소득
- 손실감내도
- 기대수익
- 자금 성격
- 실제 투자가능기간
- 필요 시 기타 고객상황

### Agent 판단 로직
```text
높은 기대수익 희망
→ 투자성향 확인
→ 손실감내도 확인
→ 투자경험 확인
→ 자금성격 / 투자기간 확인

위험감내 낮음
→ 공격적 운용 제한

위험감내 충분
+ 투자기간 충분
→ 성향 범위 내 성장자산 활용
```

## RS-05. 연령 자체보다 실제 투자가능기간에 따라 위험수준 조절

### 적용 상황
- 연령·은퇴시점이 달라졌지만 동일 포트폴리오를 유지
- 은퇴가 가까워지는데 위험자산 비중이 과거와 동일
- 연금수령 방식 변화로 실제 투자기간이 달라진 고객

### 핵심 원칙
연령 자체보다 실제로 얼마나 오래 투자할 수 있는지가 위험수준 판단에 더 중요하다. 투자기간이 길수록 시장 변동을 회복할 시간이 있고, 투자기간이 짧아질수록 큰 손실을 회복할 시간이 부족해진다.

### 교육자료상 참고 구간
```text
30대
→ 은퇴까지 20년 이상
→ 장기 성장자산 활용 여력 큼

40대
→ 은퇴까지 약 10~20년
→ 여전히 수익률 추구 가능 구간

50대
→ 은퇴까지 약 5~10년
→ 안정성 비중 확대 필요성 증가
```

※ 위 연령 구간은 교육자료상 참고값이며 강제 Rule로 사용하지 않는다.

### 참고 경험칙
자료별로 `100-나이`, `90-나이` 등 서로 다른 경험칙이 등장하므로 숫자 자체를 Rule로 사용하지 않는다.

상위 원칙은 다음과 같다.

```text
투자기간 충분
+ 손실감내 가능
→ 높은 변동성 수용 가능성 증가

투자기간 짧음
또는
자금사용 시점 접근
→ 손실 회복시간 부족
→ 위험수준 축소 검토
```

## RS-06. 은퇴 임박 시 단기 고수익 추구보다 손실방어 우선

### 적용 상황
- 퇴직 1~3년 전 고객
- 최근 상승한 ETF·테마상품으로 단기 수익률을 높이려는 고객
- 은퇴 직전 큰 적립금을 보유한 고객

### 핵심 원칙
은퇴 직전에는 큰 손실을 회복할 시간이 부족하다. 특히 적립금 규모가 큰 고객은 동일한 변동률이라도 금액 기준 손실이 커질 수 있으므로 단기 고수익보다 손실방어와 필요자금 확보를 우선한다.

### 운용 방향
- 유행상품·테마에 목돈 집중 지양
- 투자 시점 분산
- 은퇴 직후 필요한 자금은 안정자산으로 확보
- 장기 운용 가능한 잔여자금은 성향 범위 내 성장자산 유지 가능

### 판단 변수
- 퇴직까지 남은 기간
- 은퇴 직후 필요자금
- 현재 적립금 규모
- 위험자산 비중
- 투자성향
- 실제 투자가능기간

## RS-07. 직접 상품 선택·관리가 어렵다면 TDF·관리형 운용 활용

### 적용 상황
- 상품 선택이 어렵다고 느끼는 고객
- 시장에 정기적으로 관심을 가지기 어려운 고객
- 직접 리밸런싱할 시간·역량이 부족한 고객

### 핵심 원칙
실적배당 운용 의향이 있더라도 직접 상품을 선택하고 관리하기 어렵다면 TDF, 디폴트옵션 등 자산배분·자동조정 기능이 있는 관리형 운용방식을 검토한다.

### 판단 변수
- 금융상품 투자경험
- 시장·상품 이해도
- 계좌 관리 가능시간
- 직접 자산배분 역량
- 리밸런싱 의향
- 예상 은퇴시점

### Agent 판단 로직
```text
시중금리 수준의 안정적 수익에 만족?
        │
        ├─ YES
        │   → 원리금보장형 중심 검토
        │
        └─ NO
            ↓
투자경험 + 직접관리 시간/역량 충분?
        │
        ├─ YES
        │   → 직접 포트폴리오 운용 검토
        │
        └─ NO
            → TDF / 디폴트옵션 등 관리형 운용 검토
```

## RS-08. 포트폴리오는 정기적으로 모니터링하고 리밸런싱

### 적용 상황
- 장기간 운용상태를 확인하지 않은 고객
- 특정 자산 상승·하락으로 목표비중이 달라진 고객
- 고객상황 자체가 과거와 달라진 고객

### 핵심 원칙
퇴직연금은 한 번 설정하고 방치하는 자산이 아니다. 다만 매일 시장에 반응할 필요도 없다. 정기적으로 고객상황과 운용현황을 재점검하고 목표 자산배분에서 벗어난 경우 리밸런싱한다.

### 관리 Cycle
```text
자금의 성격 재진단
→ 투자 목표 재설정
→ 실제 투자가능기간 재계산
→ 목표 자산배분 재설정
→ 리밸런싱
```

### 참고 모니터링 주기
- 장기 사회초년생: 연 1회 수준의 정기점검 예시
- 은퇴까지 약 10년: 분기 단위 점검 예시
- 일반적으로 분기~반기 수준의 점검 활용 가능

※ 고정 규칙이 아니라 투자기간과 고객상황에 따라 점검 빈도를 조절한다.

### 판단 변수
- 마지막 계좌 점검일
- 마지막 리밸런싱일
- 현재 자산배분
- 목표 자산배분
- 고객상황 변화
- 은퇴까지 남은 기간
- 만기 현황

## RS-09. 목표수익률은 투자기간과 함께 설정하고 관리

### 적용 상황
- “10% 수익” 등 기간 없는 기대수익만 제시하는 고객
- 시장 움직임에 따라 즉흥적으로 매수·매도하는 고객

### 핵심 원칙
투자기간이 없는 목표수익률은 투자판단 기준으로 의미가 약하다. 목표수익률은 반드시 투자기간과 함께 설정하며 가능하면 연환산 기대수익률 형태로 관리한다.

### 운용 방향
- 목표수익률 설정
- 투자기간 설정
- 연환산 목표수익률로 관리
- 감내 가능한 손실범위 함께 설정
- 목표 달성/손실범위 초과 시 재점검

### 판단 변수
- 목표수익률
- 투자기간
- 연환산 기대수익률
- 감내손실률
- 현재 수익률
- 투자성향

## RS-10. 부진상품은 전체 포트폴리오 관점에서 단계적으로 교체

- 금리 하락 예상: 중장기채의 자본수익 가능성 검토

## RS-14. 은퇴 후 인출까지 고려해 실제 투자가능기간을 계산

### 적용 상황
- 퇴직 후 전액 인출보다 연금 형태로 노후소득으로 활용
- 은퇴 후에도 상당기간 자산을 유지할 고객

### 핵심 원칙
퇴직연금의 투자기간은 퇴직일에서 반드시 끝나는 것이 아니다. 연금으로 장기간 나누어 수령할 고객은 실제 연금수령 종료시점까지를 투자가능기간으로 보고 운용전략을 설계한다.

### Agent 판단 로직
```text
은퇴 시점 접근
→ 전액 사용 여부 확인

전액 또는 대부분 즉시 사용
→ 안정성 / 유동성 강화

연금 분할수령
→ 가까운 시기 사용할 자금과 장기 잔여자금 분리
→ 단기 사용분 안정화
→ 장기 잔여분 성장자산 유지 검토
```

### 판단 변수
- 연금개시 시점
- 예상 수령기간
- 연간 인출액
- IRP 잔액
- 장기 운용 가능금액
- 투자성향

## RS-16. 원리금보장형은 만기 후 운용공백을 최소화

### 핵심 원칙

### 운용 방향
- 상품별 만기일 확인
- 만기 전 다음 운용방향 결정
- 재예치 / 다른 원리금보장형 / 실적배당형 후보 검토

- 현금성 대기기간 최소화

### Agent 판단 로직
```text
원리금보장형 보유
→ 만기일 확인
→ 만기 후 운용계획 확인
→ 디폴트옵션 상태 확인
→ 예상 현금성 대기기간 판단
→ 재운용 후보 결정
```

## RS-17. 자동운용도 설정 후 방치하지 않고 정기 재점검

### 판단 변수
- 현재 자동운용 유형
- 최초 설정일
- 당시 투자성향
- 현재 투자성향
- 예상 은퇴시점
- 실제 투자가능기간
- 최근 변경/점검일
- 실제 자동매수 자산

### Agent 판단 로직
```text
자동운용상품 사용 중
→ 설정 당시 투자성향 확인
→ 현재 투자성향 / 은퇴계획 확인
→ 현재 상품 위험수준 확인

현재 상황과 일치
→ 유지

현재 상황과 불일치
→ 설정 변경 또는 다른 운용방식 검토
```

### 핵심 원칙

- 실제 최초 사용시점
- 연금수령 종료 예상시점

#### 3. 목표
- 목표수익률
- 노후 필요자금
- 자산수명

#### 4. 위험
- 투자성향
- 허용 손실
- 허용 변동성

#### 5. 결과
- 적정 자산배분
- 운용방식
- 상품 유형

### Agent 판단 로직
```text
자금의 성격 확인
→ 언제 사용할 자금인지 확인
→ 실제 투자가능기간 계산
→ 목표수익률 설정
→ 허용 가능한 변동성 판단
→ 적정 자산배분 결정
→ 직접관리 / 관리형 운용 판단
→ 상품 유형 선택
```

## 신규 Strategy
다음 중 하나 이상이 기존 전략과 실질적으로 다를 때만 신규 ID 부여.

1. 적용 상황이 다름
2. 핵심 운용원칙이 다름
3. Agent 판단변수가 다름
4. 최종 운용방향이 실질적으로 다름

## 기존 Strategy 보강
다음은 신규 Strategy로 분리하지 않는다.

- 적용 상황 구체화
- 판단 변수 추가
- 예외조건 추가
- Agent 판단 로직 구체화
- Brief 예시 추가
- 기존 전략에 대한 새로운 근거 추가

## 중복
표현만 다르고 Agent가 내리는 판단과 Action이 같으면 신규 Strategy로 만들지 않는다.

# 9. 현재까지의 핵심 상위 원칙

1. **퇴직연금은 상품부터 고르지 않는다.**
2. **먼저 자금의 성격과 실제 투자가능기간을 규정한다.**
3. **목표수익률은 투자기간과 함께 설정한다.**
4. **투자성향과 손실감내도를 위험수준 판단의 기본으로 사용한다.**
5. **연령 자체보다 실제 투자가능기간이 더 중요하다.**
6. **장기 운용자금은 물가와 복리효과를 고려한다.**
7. **특정 상품·국가·섹터에 집중하지 않고 실질적으로 분산한다.**
8. **은퇴가 가까워질수록 손실 회복기간과 적립금 규모를 함께 고려한다.**
9. **퇴직 후 연금수령 기간까지 투자기간으로 볼 수 있다.**
10. **직접 관리가 어렵다면 TDF·디폴트옵션 등 관리형 운용을 활용한다.**
11. **포트폴리오는 매일 볼 필요는 없지만 방치해서도 안 된다.**
12. **고객상황과 자산배분을 정기적으로 재점검하고 리밸런싱한다.**
13. **원리금보장형도 상품 선택과 만기 재운용 관리가 필요하다.**
14. **자동운용도 고객상황 변화에 따라 다시 적합성을 점검한다.**
15. **Product Knowledge와 Strategy Knowledge를 분리한다.**
16. **시장환경에 따라 변하는 전략은 Tactical Strategy로 분리한다.**

# 11. Brief 반영 방향

General Strategy는 고객별 Brief에서 주로 S2/S3 판단 근거로 활용한다.

## S1 고객 상황
- 고객의 현재 상태
- 생애주기
- 자산배분
- 주요 변화/Signal

## S2 핵심 관리 포인트
- 현재 Portfolio와 Baseline Strategy 간 Gap
- 이번 상담에서 확인할 점

## S3 관리 방향 / 제안
- 적용 Strategy
- 조건부 운용방향
- 상품은 Strategy 결정 후 구현수단으로 제시

## S4 상담 Point
- 고객에게 설명할 운용 원칙
- 반론 대응
- 사전고지

## S5 후속조치
- 상품/거래 실행
- 만기관리
- 리밸런싱
- 예약
- CRM 기록
