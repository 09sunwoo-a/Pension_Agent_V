## 1. 이 문서의 사용 계약

**고객 데이터 → 자금 목적·사용시점 → 손실감내·현재 포트폴리오 → 관리방향 → 상품군 → 실제 후보 1~3개** 순서로 사용한다. 이벤트는 상담의 시작점이고 상품 선택은 확인 결과에 따라 달라진다. 같은 고객 자금도 단기 필요분·장기 잔여분으로 나눌 수 있다.

각 PM 카드의 **상품군 선택 원칙은 교육자료**, 상품명·수치·한도는 **상품자료**, 선택 분기·검색조건·S3 문장은 **자료 기반 기획 해석**이다. 기획 분류가 기관의 공식 투자성향-위험등급 허용표를 대신하지 않는다. 해당 표가 주어지지 않았으므로 ‘위험중립형은 몇 등급까지 가능’이라는 기준을 새로 만들지 않았다.

**실제 후보 표는 분기별 예시**이지 모든 고객에게 동시에 제시할 묶음이 아니다. 고객 의향이나 적합성이 미확인이면 상품군/추가 질문까지 제시하고 후보를 확정하지 않는다. 기존 유지와 제안 보류도 정상 결과다. 현재 마스터에 후보가 없으면 상품을 만들어내거나 미등록을 판매불가로 판단하지 않는다.

**수치는 마스터와 같은 관측값의 읽기용 요약**이다. 판매목록 성과는 기준일 미확인, 월간 추천 성과는 2026-08-28이며 TDF는 2030 기준이라는 범위를 표시한다. 업데이트 때 수치의 기준은 마스터 한 곳으로 두고 여기의 읽기용 요약을 다시 생성한다. 수익률로 우선순위를 매긴 결과가 아니다.

금리·정산·최소금액·연금지급·제공한도·협의조건은 실제 제안 전 확인한다. 원금손실 거부, 사용일 충돌, 가입불가, 최소금액 미달, 필수 협의 미완료 등은 해당 후보를 배제/보류한다. 단순 데이터 미기재와 실제 부적합은 구분한다.

## 2. 상품군 선택을 위한 빠른 길잡이

아래 역할과 매핑은 자료 기반 기획 분류다. 같은 자산군도 상품별 투자한도·위험·기간이 다르다.

| 활용 목적 / 조건 | 검토 상품군·방식 | 먼저 가를 조건 | 이번 마스터의 예시 | 근거 |
|---|---|---|---|---|
| 원리금보장 운용 유지 | 정기예금·저축은행 예금·GIC | 실제 만기·금리기준·기관한도·중도해지 | DEP / SAV / GIC | E05 원리금보장 4종·원픽, S01~03 |
| 큰 금액의 원리금보장 비교 | ELB | 예금자보호 비대상 수용, 최소금액, 협의 완료 | ELB-001(내부 검토부터) | E05, S03:L19-L41 |
| 일부 변동성을 허용한 채권 운용 | 초단기/단기채 펀드·ETF | 원금보장과 구분, 실제 환매일 | ETF-001/002, FND-001/004 | E06, E08, S04/S05 |
| 국내 국채·크레딧 노출 | 국채/크레딧/중장기채 | 단기채와 다른 기간·변동성, 기존 자산과 역할 | ETF-003, FND-003, MF-017 | S04 투자전략, S05 유형, K01 RS-11 |
| 해외 채권 분산 | 글로벌 단기채·우량채·하이일드 구분 | 신용·환율·듀레이션 및 실제 70/100 한도 | FND-005/006 | S04:L162-L163, S05 |
| 은퇴시점별 자동 자산배분 | TDF(일반펀드 또는 ETF) | 실제 사용기간·빈티지·위험·보수 | MF-001~004, ETF-008/009 | E06 TDF·실전 Q3 |
| 다자산·혼합 운용 | EMP·혼합/글로벌자산배분 펀드·ETF | 실제 주식/채권/대체노출·중복 | MF-009/010, ETF-004/005 | S04:L23-L24,L174; S05 |
| 직접 대표지수 투자 | 지수형 ETF·펀드 | 투자대상·손실감내·환헤지·기존 집중 | ETF-006/007 | E06 ETF·원픽 |
| 성장/가치/테마 노출 | 주식형 펀드·ETF | 명확한 목적·집중 허용·기존 노출 | MF-005~008/012~014, FND-007/008 | S04 투자전략, E06 원픽 |
| 배당·인컴 전략 | 배당주·TIF·인컴형 | 원금 위험, 분배와 IRP 지급 별개 | ETF-010, FND-008/010 | E06 원픽; S04/S05 |
| 별도 운용지시 누락 대비 | 디폴트옵션 | 지정/보유/실행 구분, 구성위험·고객의사 | DO-001~010 | E07, E08 |
| 매수·리밸런싱까지 위임 | AI 투자일임 | 계약·이용제한·비용·실제 관리부담 | SVC-001 | E06 AI 투자일임 |

‘Core/Satellite’는 포트폴리오에서 맡기는 역할이지 상품의 고정 위험등급이 아니다. 교안의 Core=TDF/위성=테마 등의 설명은 맥락과 함께 참고하며, 특정 지수·배당상품을 모든 고객에게 ‘기본으로 안전한 상품’으로 고정하지 않는다.

## 4. 상황별 매핑 카드

<a id="PM-01"></a>

### PM-01 · 현금성자산 과다

**적용할 때 보는 데이터:** 현금성 금액·비중과 발생일 / 입금/만기/매도 후 경과기간 및 예약·주문 유무 / 현재 보유상품·투자성향.

**고객과 확인:** 지출·이전·연금수령 때문에 의도적으로 대기하는가? / 장기 운용할 금액과 원금손실 허용 여부는? / 직접 선택과 관리형 중 무엇을 선호하는가?

**관리방향:** 운용공백의 이유부터 확인한다. 불필요한 대기라면 자금 사용기간과 손실감내에 맞게 상품 운용을 검토하되 필요한 현금은 유지한다.

| 추가로 확인된 조건 | 검토 상품군/방식 |
|---|---|
| 원금손실을 원하지 않고 만기까지 유지 가능 | 정기예금·GIC |
| 일부 변동성 허용, 직접 상품 선택 희망 | 단기채 펀드/ETF |
| 장기자금·상품관리 부담 확인 | 적합한 빈티지의 TDF 또는 관리형 방식 |

**마스터 검색조건(기획용):**

```yaml
roles_any:
- 원리금보장 영역
- 저변동 추구
- 관리부담 완화
exclude_status:
- EXCLUDED
must_confirm:
- 사용일
- 손실감내
- 개인형IRP 실제 매수가능
```

**검토 조건:** 손실감내가 있는 대기자금의 채권형 검토  
**이 상황에 연결하는 이유:** 단기채 유형의 실제 클래스 후보. 이미 같은 펀드를 보유하면 신규 상품 추가보다 기존 비중을 먼저 점검한다.

ETF / 위험 4 / 보통위험  
1Y +6.12% · 기준일 미확인; σ(1Y) 6.54%; IRP 한도 100%  
**검토 조건:** 실제 투자기간과 2030 빈티지가 맞는 관리형 경로  
**이 상황에 연결하는 이유:** 직접 리밸런싱 부담을 낮출 TDF 비교 후보. 단기채와 같은 위험이라고 보지 않는다.  
**상품 사실 근거:** S05:L89, S05:L1-L10

**제외·유지·보류:** 의도된 현금 대기·이미 매수지시 진행 중이면 중복 권유하지 않는다. 원금손실 거부 고객에게 FND-001/ETF-008을 예금처럼 제안하지 않는다.

**S3에 쓸 수 있는 관리방향 문장(기획 예시):**

> 현금성으로 대기 중인 이유와 사용할 시점을 확인한 뒤, 계속 남겨둘 자금은 원리금보장형 또는 투자성향에 맞는 실적배당형으로 운용하는 방향을 검토합니다.

**후속 확인:** 현재 주문상태를 확인하고 일회성 운용 또는 입금 시 매수상품 설정 필요성을 구분한다.

**판단 근거:** E06:고객 질문 Case 3; E08:원픽 가이드 — 3차 보호막; K02:CASE 01.  
**기존 문서 연결:** RS-18, RS-16, CASE 01 (RS는 K01, CASE는 K02의 버전 기준).

### PM-02 · 원리금보장상품 중심 / 100% 운용

**적용할 때 보는 데이터:** 현재 예금·GIC 비중과 만기 / 투자성향 분석일·상품변경 이력 / 장기 미변경 여부.

**고객과 확인:** 노후자금만큼은 원금보장을 원해서 선택했는가? / 앞으로 실제 사용시점은 언제인가? / 기존 안정성을 유지하면서 일부 투자상품을 비교할 의향이 있는가?

**관리방향:** 원리금보장 100% 자체를 문제로 규정하지 않는다. 의도된 안정 운용은 유지하고, 장기 운용·투자의향·손실감내가 함께 확인될 때만 일부 분산 대안을 찾는다.

| 추가로 확인된 조건 | 검토 상품군/방식 |
|---|---|
| 의도된 원금보장 운용 | 현재 상품 유지 또는 원리금보장 내 금리·만기 점검 |
| 일부 실적배당 의향·분산 필요 확인 | 혼합/다자산 펀드 |
| 장기자금·관리부담 확인 | TDF |

**마스터 검색조건(기획용):**

```yaml
initial_action: 유지 이유 확인
forms_any:
- 정기예금
- GIC
- 일반펀드
- ETF
required_confirmations:
- 실제 투자 의향
- 투자기간
- 허용 위험
portfolio_scope: 변경할 일부 자금만
```

## 5. 월간 추천 포트폴리오를 실제 상품으로 찾는 예시

**‘위험중립형 → 무조건 MF-015/MF-011/MF-009를 해당 비중으로 매수’가 아니다.** 원문 모델은 아래 배분의 참고안이다. 고객의 기존 보유·실제 의도·투자기간을 먼저 확인한 뒤 필요한 일부 역할만 구현할 수 있다. 해당 비중이나 모델 이름으로 투자성향 적합성 확인을 대체하지 않는다.

| 원문 모델 구성(S04:L165-L174) | 모델 내 비중 | 월간 약칭 레코드 | 이번 B01의 실제 클래스 연결 후보 |
|---|---:|---|---|
| 국내채권: 키움 더드림 단기채 | 60% | [MF-015](PRODUCT_MASTER.md#MF-015) | [FND-001](PRODUCT_MASTER.md#FND-001) — 월간자료의 클래스는 미확인 |
| 해외채권 표기: 우리미국 단기채공모주(H) | 15% | [MF-011](PRODUCT_MASTER.md#MF-011) | [FND-002](PRODUCT_MASTER.md#FND-002) — 실제 목록 유형은 채권혼합 |
| 해외혼합: 삼성EMP 리얼리턴(UH) | 25% | [MF-009](PRODUCT_MASTER.md#MF-009) | 이번 B01에서 클래스 미확정. 약칭 수준 후보만 사용 |

월간 약칭의 1Y 수익률과 판매목록 실제 클래스의 1Y 수익률은 같지 않을 수 있다. 예컨대 **키움 더드림 단기채**는 월간 표에서 2.39%(2026-08-28, 클래스 미특정), 이번 선별 클래스 C-P2E는 2.52%(기준일 미기재)다. 이를 임의로 한 값으로 합치지 않았다. 표기 대상 클래스와 관측 출처를 고정한 뒤 브리핑에 사용한다. (S04:L31, S05:L205)

현재 단기채를 이미 충분히 보유한 고객에게 성장/분산을 보완하려는 상담이라면, 같은 단기채를 또 제시하는 것으로 끝내지 않고 **혼합·다자산·적합한 TDF 등의 다른 역할**을 확인한다. 다만 원금보장 유지가 목적이면 그 역할에 맞는 기존 유지/원리금보장 내 비교를 선택한다.

## 6. 브리핑 상품 카드 조립 예시

## 9. 출처 범위와 추가 사용 지침

출처 ID·정확한 파일명·교육자료 `main` 파일 SHA는 [상품 마스터의 출처 절](PRODUCT_MASTER.md)에서 확인한다. S01~S05는 이번에 첨부된 상품자료, E05~E08은 지정 저장소의 연금왕 찐천재, K01~K03은 기존 기획문서다. 원문 사실과 기획 해석을 혼동하지 않는다. 이 문서의 성향·기간별 분기는 공통 판단 기준이며 고객을 특정 위험등급 상품에 자동 승인하는 룰이 아니다.

다른 AI와 기획할 때 아래 지침으로 사용할 수 있다.

> 고객 사실과 미확인 의사를 구분한 뒤 이 문서에서 가장 관련 있는 PM 카드 1~2개를 찾는다. 사용시점·손실감내·기존 보유에 맞는 분기를 고르고 PRODUCT_MASTER의 실제 ID로 후보를 연결한다. 상품명·종류·위험·성과/금리·특징·한도와 해당 고객에게 검토하는 이유를 제시한다. 알려지지 않은 고객 의사·클래스·성과 기준일·현재 매수 가능 여부를 지어내지 않는다. 원금손실 거부·사용일 충돌·가입불가·최소금액 미달·필수 협의 미완료이면 제외/보류하고, 기존 유지도 대안으로 둔다. 마스터에 후보가 없으면 없는 범위를 밝히고 추가로 필요한 상품군만 특정한다.

판매목록은 이번 B01 20행만 상세 구조화했다. 남은 272행은 다음 요청이 있을 때 필요한 상황의 공백을 채우는 순서로 추가한다. 다른 문서·코드·HTML·원천파일·기존 고객사례는 수정하지 않았다.
