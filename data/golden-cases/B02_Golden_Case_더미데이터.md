#### S1

| 번호 | S1 문장 | JSON 근거 Field | 결과 |
|---|---|---|---|
| 1 | 30대 후반 고객으로, IRP에 매월 일정 금액을 자동이체 | 화면직접표시데이터.고객정보.나이 = 38 / IRP계좌현황.개인부담금자동이체 | PASS |
| 2 | 납입은 꾸준하지만 상품매수는 몇 달에 한 번씩 이루어짐 | 최근거래및변화 T001~T009 / 계산값.최근7개월개인부담금입금횟수 = 7 / 최근7개월상품매수횟수 = 2 / 최근상품매수간격일수 = 91 | PASS |
| 3 | 입금 시 매수상품 미지정 | IRP계좌현황.입금시매수상품.설정여부 = false | PASS |

#### S2/S3

Evidence  
→ 월 60만원 자동이체 입금은 이어졌지만 최근 7개월의 매수는 2회이며, 마지막 매수 뒤 7·8월 입금분 120만원이 고유계정대로 남아 있다. 입금 시 매수상품은 설정되어 있지 않다.

S2에서의 Interpretation  
→ 납입과 매수가 분리돼 반복 운용공백이 발생한 사실은 설명된다. 다만 지연이 고객의 직접 판단인지 단순 누락인지는 데이터로 확정하지 않았다.

아직 고객에게 확인해야 할 것  
→ 대기 이유, 대기자금의 근시일 사용계획, 자동매수 희망 여부, 원금보장 선호와 손실감내 범위.

S3가 조건부로 제시하는 Strategy  
→ 현재 대기자금 120만원의 별도 매수와 향후 월 납입분의 매수설정을 분리한다. 정기예금·단기채는 고객의 유지기간과 위험수용 의사가 확인된 뒤 비교하는 후보이며, JSON에는 어느 쪽 의향도 선입력하지 않았다.

### 3. 최소성 검토

[PASS] 브리핑에 필요하지 않은 필드를 불필요하게 채우지 않았다.  
[PASS] 확인되지 않은 고객 의향을 생성하지 않았다.  
[PASS] S4 예상반응을 CRM Fact로 만들지 않았다.  
[PASS] Digital Signal을 고객 의사로 확대해석하지 않았다.  
[PASS] 타계좌 상품매수를 IRP 투자 의사로 확대해석하지 않았다.  
[PASS] 실제 상품명이나 상품마스터 ID를 임의 생성하지 않았다. 현금성자산은 상품명이 아닌 자산상태 표기다.  
[PASS] 보유상품 합계 14,680,000원 = IRP 평가금액이며, 자산유형 금액과 비중 합계가 각각 일치한다. 마지막 매수 후 입금 1,200,000원 = 현재 대기자금이다.  
[PASS] S1 세 줄 모두 JSON에서 직접 설명된다.  
[PASS] S2/S3가 JSON Evidence와 모순되지 않는다.
